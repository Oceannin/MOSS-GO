# Ручная проверка конкурсной версии

Чтобы успеть подать работу, расширенные проверки перенесены из обязательного
прогона. Основной сценарий и ограничения описаны в README и release notes.

## Перед отправкой — около пяти минут

1. Откройте публичный GitHub без авторизации: README, LICENSE, установка, workflow
   и файлы Release должны быть доступны. Проверьте ссылки на демо и социальный пост.
2. Посмотрите демо целиком: оно короче двух минут, интерфейс английский, используются
   оригинальные персонажи. Ускорение ожидания должно быть обозначено.
3. Для локального запуска используйте проверенный FLUX Balanced pack на 16 GB.
   Если приложение уже настроено, выберите пример и один вариант, создайте сцену,
   скачайте изображение и Recipe. Не выбирайте экспериментальный CharRef для демо.
4. В форме укажите фактически использованные модели. FLUX.2 Klein не даёт права
   отмечать бонус FLUX 3. Live link оставьте пустым, если нет удалённого генератора.
5. Самостоятельно прочитайте соглашения формы, отправьте заявку и сохраните
   подтверждение. Регистрация и сохранённый черновик не заменяют отправку.

## Можно проверить после отправки

- Chrome/Edge: увеличение всего интерфейса до 200%, клавиатура и экранный диктор.
  Масштаб изображения 200% в Inspect image не заменяет проверку масштаба браузера.
- Короткий экран в альбомной ориентации, длинные сообщения об ошибке и собственные
  очень большие изображения. Проверьте доступность кнопок и сохранность маски.
- Отмена собственного задания во время sampling: остановиться должен выбранный
  batch MOSS GO; посторонние задания ComfyUI должны сохраниться. Не проводите
  такую проверку параллельно с важной работой без резервного сохранения.
- Чистая установка GPU-окружения, Linux и реальные 12/24 GB GPU. До проверки не
  считайте эти конфигурации подтверждёнными.
- Необязательный Ollama-помощник и экспериментальные модели. Они не нужны для
  основной конкурсной демонстрации. Отдельно проверьте лицензии любых добавленных
  самостоятельно моделей, LoRA, музыки и референсов.

Эти пункты не мешают отправить честно описанную конкурсную preview-версию, но не
должны превращаться в утверждения о проверенной совместимости.
