# Ручные проверки — 0.2.0-rc.1

Основные три сценария FLUX 3, официальный upsampler, четыре локальные правки и
три legacy-движка проверены на настоящей RTX 4070 Ti SUPER 16 GB / Windows.
Это список **оставшихся** проверок, не список заявленных успешных результатов.

1. Отмена во время семплирования: создать отдельный тестовый каталог, запустить
   один FLUX 3 job и отменить после начала шагов. Убедиться, что следующий свой
   job работает, а чужая очередь не затронута. Не проверять на важной чужой задаче.
2. Реальный browser zoom 200%: формы, Details, Recipe, маска, клавиатурный фокус.
   Масштабирование самой картинки — отдельная функция, оно уже реализовано.
3. Экранный диктор: пройти Generate, настройки, маску прямоугольником, историю,
   диалоги Details и Recipe; проверить озвучивание ошибок и возврат фокуса.
4. Другие физические GPU / Linux GPU / BF16: отдельная проверка установки,
   времени и памяти. Не считать выбранный профиль подтверждением совместимости.
5. Полностью чистое GPU-окружение: отдельная установка официального ComfyUI
   0.41.2, совместимого Torch/CUDA и node pack. Текущая GPU-проверка использовала
   изолированный ComfyUI с уже установленными GPU-пакетами.
6. Перед Submit: проверить публичные ссылки, видео короче двух минут, социальный
   пост с #OpenSourceHiggsfield и четыре соглашения формы. Соглашения подтверждает
   автор. Статическая страница не является live-генератором.

Результаты и выявленный промах позы Mira опубликованы отдельно в
[FLUX3_BENCHMARK](FLUX3_BENCHMARK.md). Непроверенные пункты не блокируют изучение
локального release candidate, но остаются ограничениями его заявлений.

Финальные EN/RU Details, обе темы, маска и сравнение проверены на 1280×720.
Публичный landing дополнительно проверен 3 ноября в настоящих браузерных iframe
шириной 390 и 320 CSS px: горизонтального переполнения нет, CTA и переход к видео
работают. Это проверка responsive CSS, а не физического iPhone/Android.
Повторная проверка новых контролов на 320/390 px остаётся ручной: доступный
браузерный viewport API не применил заданный размер (фактический viewport
оставался 1280×720). Не представляем эту попытку как успешный мобильный тест.
