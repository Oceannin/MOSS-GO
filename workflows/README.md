# Example ComfyUI API graphs

The recommended examples are `flux3-create-api.json`,
`flux3-reference-api.json` and `flux3-masked-refine-api.json`.
They are generated by `python scripts/export_workflows.py` using the application
builder. They are examples, **not a record of an executed take**.

Use ComfyUI 0.41.2 with the MOSS GO node pack and the four files in
[the FLUX 3 pack](../docs/MODELS.md). Load the JSON as an API workflow, upload
`mira.png` from `moss_go/web/examples/` and, for Refine, `mira-edit-mask.png`.
Update the `LoadImage`/mask loader filenames to the actual uploads. White means
editable. Keep source dimensions 768×1024 for this example mask. The official
local upsampler is enabled; these are 16-step Euler/simple distilled graphs.

For an **actual execution**, use Recipe on a completed studio take. The portable
ZIP contains the exact graph, original and observed expanded prompt, sources,
mask and result. Inputs have catalog-specific names; bind them to your own
ComfyUI uploads when moving the graph. The JSON is the native API prompt format,
not a hand-positioned visual canvas layout.

Legacy examples remain: `moss-create-api.json`, `flux-create-api.json`,
`flux-reference-api.json`, `flux-masked-refine-api.json`. They retain FLUX.2/MOSS
component names and sampling settings. They do not qualify as FLUX 3 evidence.
