# Changelog

## 0.2.0-rc.1 — 2026-11-03

FLUX 3 Image Klein is the default for Create, Reference and masked Refine, with
actual official local prompt upsampling and observed caption/model metadata.
Adds native model-specific graphs, gated checksum-verified model setup,
mode-aware readiness and result details. Keeps legacy engines, recipes, catalog
history and explicit saved engine choices. Includes a new original-output
showcase and a separate 13-case GPU evaluation with retained failures.
Application code remains Apache-2.0; FLUX 3 weights use FLUX Kommunity License.
See [release notes](docs/RELEASE_NOTES.md) for measured limits and rollback.

## 0.1.0-rc.1

First contest preview: standalone local ComfyUI studio, original reference
examples, safe character traits, FLUX reference and masked refinement, MOSS SFT
creation, scene packs, durable versions and recipe/graph export. Includes English
by default, Russian translation, two themes, model setup with hashes, conservative
hardware profiles and recovery from uncertain launches and memory failures.

This preview records unverified configurations and optional manual checks in
[release notes](docs/RELEASE_NOTES.md).
